## SYNDICATE GUILD 
<p>Бот для управления и автоматизации процессов через дискорд.</p>

<hr/>

#### На данный момент реализовано:
 - Интеграция с Google Sheets API 
 - Интеграция с Discord
 - Команды для управления складом

 <hr />

 #### Для запуска:
<code>npm i && npm run dev</code>

#### Музыка в голосовом канале

Нужен Node.js 22.12+ и актуальный yt-dlp. FFmpeg и кодек Opus устанавливаются через npm.
`npm run build` автоматически устанавливает yt-dlp, если его ещё нет.

```sh
npm install
npm run setup:music
npm run build
npm start
```

`setup:music` скачивает официальный yt-dlp в `tools/` и проверяет SHA-256.
Можно использовать свою установку: задайте `YT_DLP_PATH` в `.env` (полный путь
к исполняемому файлу), либо добавьте `yt-dlp` в PATH. Для обновления повторите
`npm run setup:music`. При ручной установке через Python используйте
`python -m pip install -U "yt-dlp[default]"`, чтобы установить компоненты YouTube.
Бот передаёт yt-dlp путь к своему Node.js для обработки YouTube.
Если YouTube отвечает «Sign in to confirm you're not a bot», добавьте cookies
прямо в `.env` или в секретную переменную окружения хостинга:

```env
YT_DLP_COOKIES="SID=ваше_значение; HSID=ваше_значение; SAPISID=ваше_значение"
```

Вставляйте целиком значение заголовка `Cookie` из запроса к YouTube:
DevTools → Network → запрос к `youtube.com` → Request Headers → Cookie.
Пример выше показывает формат; названия и значения берите из своего запроса.
В панели хостинга задайте имя `YT_DLP_COOKIES` и само значение без внешних кавычек.

Также можно вставить полное содержимое экспорта в формате Netscape:

```env
YT_DLP_COOKIES="# Netscape HTTP Cookie File
.youtube.com\tTRUE\t/\tTRUE\t0\tSID\tваше_значение
"
```

Поддерживаются настоящие переносы строк и табуляции, а также `\n` и `\t`.
Бот сам создаёт временный cookies-файл для каждого вызова yt-dlp и удаляет его
после завершения процесса. Загружать отдельный файл на сервер не нужно.
`YT_DLP_COOKIES` имеет приоритет над прежним `YT_DLP_COOKIES_PATH`, который
по-прежнему поддерживается. После изменения переменных перезапустите бота.
Инструкции: [yt-dlp: экспорт cookies YouTube](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies).
Cookies содержат данные авторизации: не публикуйте их и `.env` в Git.

#### Деплой на Railway

Build Command: `npm run build`. Start Command: `npm run start`.
Сборка сама скачает yt-dlp для Linux; коммитить папку `tools/` не нужно.
Версия Node.js задана в `package.json`: 22.12+ в пределах Node.js 22.
Если задана переменная `RAILPACK_NODE_VERSION`, она имеет приоритет:
задайте ей `22` или удалите переопределение.

Секреты задавайте в Railway Variables. Для `YT_DLP_COOKIES` вставляйте само
содержимое cookies, без `YT_DLP_COOKIES=` и без внешних кавычек из `.env`.
Переменные `YT_DLP_PATH` и `YT_DLP_COOKIES_PATH` для автоматической установки
и cookies из окружения не нужны. Не переносите туда локальные Windows-пути.
После отправки кода в подключённый репозиторий Railway соберёт и запустит бота.
В Deploy Logs должны появиться сообщения авторизации и регистрации команд.

- `/play url:<ссылка YouTube>` — бот входит в ваш голосовой канал и включает звук
  видео. Следующие треки добавляются в общую очередь по порядку команд.
- `/queue` — текущий трек, авторы и первые 10 треков очереди.
- `/clear-my-tracks` — удалить все свои треки, включая воспроизводимый.

При выходе или переходе в другой канал пользователь теряет все свои треки,
включая загружающиеся. Треки других участников сохраняются. Когда канал пуст,
бот отключается; при пустой очереди — через 60 секунд. Очередь хранится в памяти,
отдельно для каждого сервера; один бот играет в одном канале сервера. Максимум
20 треков на пользователя. Плейлисты, прямые трансляции и Stage-каналы не поддерживаются.
Ошибки воспроизведения записываются в журнал, бот переходит к следующему треку.

Боту нужны права View Channel, Connect и Speak; в канале должно быть свободное место.
После перезапуска новые команды регистрируются на серверах из `AVAILABLE_CHANNELS`
(или на всех серверах, если список пуст).
